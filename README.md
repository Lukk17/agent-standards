# agent-standards plugins

Generated by `tools/gen_plugins.py` from `tools/plugins.yaml` on the default branch of https://github.com/Lukk17/agent-standards. Every push there rebuilds this branch, so never edit it by hand.

Add the marketplace from this branch:

```bash
claude plugin marketplace add Lukk17/agent-standards#plugins
```

Install one plugin, which also installs the plugins it depends on:

```bash
claude plugin install python@agent-standards
```
