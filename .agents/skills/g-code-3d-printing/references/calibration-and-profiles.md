# Calibration, post-processing, multi-material, and profile control

Everything that is per-filament, per-material, or per-profile rather than per-move. The safety and sequencing rules
live in [SKILL.md](../SKILL.md).

---

### Filament calibration

Before generating production G-code for a new filament, record all three:

- Pressure advance (Klipper, `SET_PRESSURE_ADVANCE ADVANCE=<value>`) or linear advance K-factor (Marlin,
  `M900 K<value>`), tuned for that filament and hotend pair, to remove corner bulge.
- Extrusion multiplier, calibrated on a single-wall cube, wall thickness within 2 percent of the configured line
  width.
- Retraction distance and speed: roughly 0.5 to 2.0 mm on direct drive, 4 to 7 mm on Bowden, tuned until stringing
  between features is gone.

Pass:

```gcode
SET_PRESSURE_ADVANCE ADVANCE=0.042
```

Fail:

```gcode
SET_PRESSURE_ADVANCE ADVANCE=0.05
```

The failing line is the default someone left in place. Store every calibrated value in a version-controlled slicer
profile next to the G-code it produced.

### Post-processing patterns

Fan off for the first two layers, then ramp to the profile value from layer 3, through the slicer's layer-change
hook rather than by editing output. Place seams at the rear of the model or on a sharp corner. Use `G10` and `G11`
firmware retract only once the firmware's retract values are tuned, otherwise use explicit E-axis moves, which are
reproducible across machines.

Pass:

```gcode
M106 S255
```

Fail:

```gcode
G10
```

### Multi-material

Define a `TOOL_CHANGE` macro per extruder in Klipper, or `T0` and `T1` sequences in Marlin, and invoke it. Never
generate a raw inline tool change. Follow every change with a prime tower or a purge bucket wipe to clear residual
colour, and bring both nozzles to their independent targets before the change begins.

Pass:

```gcode
TOOL_CHANGE TOOL=1
```

Fail:

```gcode
T1
G1 E30 F300
```

### Slicer profile version control

Keep profiles in the repository under `slicer-profiles/`: PrusaSlicer `.ini`, OrcaSlicer `.json`, Cura `.cfg` or
`.curaprofile`. Name each one for filament type, nozzle size, and layer height, for example
`pla-0.4mm-0.2mm-layer.ini`. Tag the profile in the output header so any printed part can be reproduced exactly.

Pass:

```gcode
; Profile: pla-0.4mm-0.2mm-layer.ini v1.3, OrcaSlicer 2.1.0, Voron 2.4 350mm
```

Fail:

```gcode
; generated by slicer
```
