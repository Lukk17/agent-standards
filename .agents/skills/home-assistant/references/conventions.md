# Conventions

Companion reference for the [home-assistant](../SKILL.md) skill. Load it when judging how far to trust a fact in the topic files.

---

### Verification marks

Reference facts are marked VERIFIED with the source read, INFERRED with a confidence, or UNVERIFIED. Each topic file names the source it read.

Most breakage here is not a bug, it is a reference that pointed at something transient, a condition that only failed at runtime, or a change made with no way back.
