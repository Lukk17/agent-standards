# Standards Checklist: Python

The standards checklist items for a diff that touches Python. Run them in Step 3, after the items in SKILL.md that every diff gets. Every item names the skill that owns the rule and its reasoning, so a finding can cite it.

---

### Python

- [ ] A script is a thin command-line entry calling single-responsibility modules of pure functions, each with pytest tests. `python-patterns`
- [ ] No long comment block in a module or above a function. `python-patterns`
