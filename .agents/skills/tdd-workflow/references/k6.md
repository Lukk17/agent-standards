# k6 Thresholds

The performance gate from [advanced-testing.md](advanced-testing.md#performance-gates) written for k6. Open it when a load test runs on k6.

---

### Thresholds inside the load test

Assert thresholds inside the load test so a regression fails the run rather than needing someone to read a chart.

```javascript
export const options = {
  thresholds: {
    http_req_duration: ['p(99)<200'],
    http_req_failed: ['rate<0.01'],
  },
}
```
